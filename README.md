# eduction_grow_ai

Ежедневный тренажёр по AI/LLM и стеку проектов Stan (Hermes Memory, боты, RAG, MCP, VPS).

## Как проходит день (важно)

1. **Сначала теория в чате** с ботом AI Grow Trainer — понятия, схема, зачем это в твоих проектах, простой код.
2. **Потом** ~10 тестов RU+EN **в том же чате** (интерактивно).
3. Репозиторий — архив урока + `progress.md`, не место «сдачи» тестов.

## Файлы дня

В `days/YYYY-MM-DD/`:

| Файл | Содержание |
|------|------------|
| `lesson.md` | Теория + примеры кода (зеркало того, что было в чате) |
| `quiz.md` | ~10 тестов, каждый блок **RU** + **EN** |
| `answers.md` | Ответы + короткое объяснение |
| `results.md` | Результат после прохождения в чате |

Прогресс: [`progress.md`](./progress.md)  
Дорожная карта: [`curriculum.md`](./curriculum.md)

## Правила

1. Не открывай `answers.md` до попытки в чате.
2. Темы из реальных проектов (Hermes Memory, GitHub), не абстрактные туториалы.
3. Ответы — боту в чат; он обновит `progress.md`.
