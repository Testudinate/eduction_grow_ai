# eduction_grow_ai

Ежедневный тренажёр по AI/LLM и стеку проектов Stan (Hermes Memory, боты, RAG, MCP, VPS).

## Формат дня

Каждый день в `days/YYYY-MM-DD/`:

| Файл | Содержание |
|------|------------|
| `lesson.md` | Короткая теория + 1–2 простых примера кода (RU) |
| `quiz.md` | ~10 тестов, каждый блок **RU** + **EN** |
| `answers.md` | Ответы + короткое объяснение (смотри после попытки) |

Прогресс: [`progress.md`](./progress.md)  
Дорожная карта тем: [`curriculum.md`](./curriculum.md)

## Правила

1. Сначала ответь на quiz сам — потом открывай `answers.md`.
2. Темы берутся из твоих реальных проектов (Hermes Memory, GitHub), не из абстрактных туториалов.
3. Ответы на тесты можно прислать боту в чат — он проверит и обновит `progress.md`.

## Как отвечать на тесты

В чат боту, например:

```
День 2026-09-16
1. B
2. hybrid
...
```

Или свободным текстом — бот разберёт.
